# Buscador de archivos

Este programa busca la palabra "home" dentro de los archivos de una carpeta y muestra las rutas donde aparece.

## Integrantes
- Integrante 1: Recorrido de archivos y carpetas
- Integrante 2: Busqueda de la palabra "home"
- Integrante 3: Programa principal e integracion

## Requisitos
Python 3

## Instrucciones
1. Descargar el repositorio.
2. Abrir una terminal dentro de la carpeta del proyecto.
3. Ejecutar: python3 main.py
4. Escribir la ruta de la carpeta donde se desea buscar.

## Funcionamiento
El programa utiliza listar_archivos(carpeta) para obtener los archivos y buscar_palabra(archivos, "home") para encontrar coincidencias.

Finalmente muestra las rutas encontradas o un mensaje si no hay coincidencias.
